# Финансовый Telegram бот

Telegram бот для управления личными финансами, получения курсов валют и советов по экономии денег.

## 🚀 Функционал

### Основные возможности:
- **Регистрация пользователей** - создание профиля в базе данных
- **Курсы валют** - актуальная информация о USD/RUB и EUR/RUB
- **Советы по экономии** - 20 практических советов для сбережения денег
- **Личные финансы** - трекер расходов по категориям с FSM (конечные автоматы)

### Технические особенности:
- Асинхронная архитектура на aiogram 3.x
- SQLite база данных для хранения пользователей и расходов
- Интеграция с внешним API курсов валют
- Динамические клавиатуры
- FSM для управления состояниями диалога

## 📋 Команды бота

- `/start` - Запуск бота и отображение главного меню
- `/help` - Справка по использованию
- **Регистрация** - Создание аккаунта пользователя
- **Курс валют** - Получение актуальных курсов USD и EUR
- **Советы по экономии** - Случайный совет по экономии денег
- **Личные финансы** - Добавление и отслеживание расходов

## 🛠 Установка и настройка

### Требования
- Python 3.8+
- aiohttp
- aiogram 3.x
- python-dotenv

### Установка зависимостей

```bash
# Создание виртуального окружения
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# .venv\Scripts\activate    # Windows

# Установка пакетов
pip install aiogram aiohttp python-dotenv
```

### Настройка окружения

1. Скопируйте `template.env` в `.env`:
   ```bash
   cp template.env .env
   ```

2. Заполните переменные окружения в `.env`:
   ```env
   TOKEN=your_telegram_bot_token
   LOG_LEVEL=INFO
   DB_PATH=finance_bot.db
   API_URL=https://v6.exchangerate-api.com/v6/{API_KEY}/latest/USD
   API_KEY=your_exchangerate_api_key
   ```

3. Получите токен бота в [@BotFather](https://t.me/BotFather)
4. Зарегистрируйтесь на [ExchangeRate-API](https://exchangerate-api.com/) для получения API ключа

### Запуск

```bash
python main.py
```

## 🗄 База данных

### Таблица users
- `user_id` - Telegram ID пользователя
- `name` - Полное имя пользователя
- Другие поля для хранения финансовых данных

### Возможности работы с БД:
- `db_create()` - Создание таблиц
- `db_add()` - Добавление записей
- `db_select()` - Выборка данных
- `db_update()` - Обновление записей

## 💰 Функция "Личные финансы"

Использует FSM (Finite State Machine) для пошагового сбора данных о расходах:

1. **Состояние cat1** - Ввод первой категории расходов
2. **Состояние costs1** - Ввод суммы для первой категории
3. **Состояние cat2** - Ввод второй категории
4. **Состояние costs2** - Ввод суммы для второй категории
5. **Состояние cat3** - Ввод третьей категории
6. **Состояние costs3** - Ввод суммы и сохранение в БД

## 📈 API курсов валют

Бот использует ExchangeRate-API для получения актуальных курсов валют:
- USD/RUB - прямой курс из API
- EUR/RUB - рассчитывается через USD
- Асинхронные запросы с использованием aiohttp

## 🎯 Советы по экономии

Бот содержит коллекцию из 20 практических советов:
- Ведение бюджета и планирование

## 🔧 Настройка логирования

В `.env` файле установите уровень логирования:
- `DEBUG` - подробная отладочная информация
- `INFO` - общая информация (рекомендуется)
- `WARNING` - только предупреждения
- `ERROR` - только ошибки
- `CRITICAL` - критические ошибки

## 🐛 Решение проблем

### Ошибка "Use async with instead"
Если видите эту ошибку, убедитесь что используете:
```python
async with ClientSession() as session:
    # ваш код
```

### Проблемы с базой данных
Убедитесь что файл БД доступен для записи и путь в `.env` корректный.
